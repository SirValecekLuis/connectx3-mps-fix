# Example: ASRock B760 Pro RS/D4 + ConnectX-3 Pro MCX314A-BCCT (slot PCIE3)

Generated by `Install-MpsFix.ps1 -GenerateOnly` from the probe values of the test system. The commands are identical
to the script that has been running on that system (only the folder name differed during development).
**Do not copy these files to your PC** - bus numbers, register offsets and values depend on your board, slot and BIOS.
Generate your own with the probe (README, section 7).

## Values read by the probe (UEFI Shell, before Windows)

| Device | Register | Value | Meaning |
|---|---|---|---|
| Card `08:00.0` | 0x00 | `0x100715B3` | vendor 15B3 (Mellanox), device 1007 (ConnectX-3 Pro) |
| Card | 0x60 | `0x0002C010` | PCI Express capability at 0x60 (v2, endpoint) |
| Card | 0x64 | `0x11D08E02` | Device Capabilities: MPS supported 512 B |
| Card | 0x68 | `0x2000` | Device Control: **MPS 128 B**, MRRS 512 B |
| Card | 0x6A | `0x0000` | Device Status: no error (CSM on, option ROM not launched) |
| Root port `00:1c.4` | 0x00 | `0x7A3C8086` | Intel 700-series PCH PCIe Root Port #5 |
| Root port | 0x18 | `0x00080800` | primary bus 00, secondary 08, subordinate 08 |
| Root port | 0x48 | `0x0020` | Device Control: **MPS 256 B**, MRRS 128 B |

Fix: card `08:00.0` register `0x68` ← `0x2020` (MPS 256 B, everything else unchanged).

## Files

* [`EFI/mpsfix/startup.nsh`](EFI/mpsfix/startup.nsh) - the boot script
* [`EFI/mpsfix/ref.txt`](EFI/mpsfix/ref.txt) - the three reference values for the safety interlock

## Result

Windows 11 25H2, WinOF 5.50.14740, firmware 2.43.7028: `mlx4_bus` initializes the card on every boot, the
40GbE port links up at 40 Gbps (PCIe Gen3 x4 limits real throughput to roughly 25 Gb/s).
